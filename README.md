# randevu-sistemi
ilk menümüz giriş kısmı eğer üyeliğimiz yoksa üye kaydı yapılacak . giriş yapıldı ise randevu işlemleri menüsü geliyor işlemler ; randevu alma , güncelleme , silme ve listeleme yapılan işlemler veri tabanına kaydolmaktadır. kaç kullanıcının üye olduğu dosyaya kaydedilmektedir. doktor menüsü ise randevu silme ve kaç kişinin üyeliği var görebilir
